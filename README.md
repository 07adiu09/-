# 按键控制 LED 亮灭（含软件消抖）

基于 **STM32F103C8T6** 开发板 + **Keil MDK5** + **STM32F10x 标准外设库** 的按键控制实验。
每按下按键一次，LED 的亮灭状态翻转一次，并通过软件延时实现**按键消抖**。

---

## 一、硬件连接

| 外设 | 引脚 | GPIO 模式 | 说明 |
|---|---|---|---|
| LED | **PB10** | 推挽输出 `GPIO_Mode_Out_PP` | **低电平点亮**（3.3V→电阻→LED→PB10） |
| 按键 | **PB11** | 上拉输入 `GPIO_Mode_IPU` | 按下接地，读到 `0`；松开读到 `1` |

> 按键使用**内部上拉**，因此松开时引脚被拉到高电平，按下时通过按键接地变为低电平。
> 这一点决定了判断逻辑：**读到 0 表示按下**。

---

## 二、功能说明

1. 上电后 LED 默认熄灭（`main` 中先执行 `GPIO_SetBits(GPIOB, GPIO_Pin_10)`）
2. 每按下按键一次，LED 亮灭状态翻转一次
3. 通过软件延时消除机械按键抖动，保证**一次按压只翻转一次**

---

## 三、按键消抖原理

### 1. 为什么需要消抖

机械按键内部的金属触点存在**弹性**。按下和松开的瞬间，触点会发生连续多次的弹跳，
导致引脚电平在这段时间内快速跳变，而不是干净利落地变化一次：

```
理想波形：  ──────┐                    ┌──────
                  └────────────────────┘

实际波形：  ──┐┌┐┌┐┌┐┌───────────────┐┌┐┌┐┌──
              └┘└┘└┘└┘                └┘└┘└
            └─抖动─┘                └─抖动─┘
            约 5~10ms                约 5~10ms
```

如果不做处理，单片机会把**一次按压误判成多次按压**，表现为 LED 乱闪。
消抖的目的就是**把抖动期跳过去，只在电平稳定后采信**。

### 2. 本代码的实现方式

`Key.c` 中的 `Key_GetFlag()` 采用「**延时 + 等待松手**」的方式：

```c
uint8_t Key_GetFlag(void)
{
    uint8_t Flag = 0;

    if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_11) == 0)   // ① 检测到低电平（疑似按下）
    {
        Delay_ms(10);                                      // ② 延时 10ms，跳过按下抖动
        while (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_11) == 0);  // ③ 持续等待按键松开
        Delay_ms(10);                                      // ④ 延时 10ms，跳过松开抖动
        Flag = 1;                                          // ⑤ 确认一次有效按键
    }

    return Flag;
}
```

流程解析：

| 步骤 | 作用 |
|---|---|
| ① 判断读到 `0` | 检测到可能有按键动作 |
| ② `Delay_ms(10)` | 等按下抖动结束，此时电平已稳定 |
| ③ `while(...==0)` | 阻塞等待，直到按键真正松开 |
| ④ `Delay_ms(10)` | 跳过松开瞬间的抖动 |
| ⑤ 返回 1 | 一次「按下 + 松开」只产生**一次**有效触发 |

**关键点**：第 ③ 步的等待松手循环，使得按住不放时不会重复触发，
必须**完整地按一次再松开**，LED 才翻转一次。

### 3. 主循环如何调用

`main.c` 采用**轮询查询**的方式：

```c
while (1)
{
    if (Key_GetFlag() == 1)   // 检测到一次有效按键
    {
        LED_Turn();           // 翻转 LED 状态
    }
}
```

## 四、LED 状态翻转的实现

`LED.c` 中的 `LED_Turn()` 通过**读取当前输出状态再取反**来实现翻转：

```c
void LED_Turn(void)
{
    if (GPIO_ReadOutputDataBit(GPIOB, GPIO_Pin_10) == 1)   // 当前是高电平（灭）
    {
        GPIO_ResetBits(GPIOB, GPIO_Pin_10);                // 拉低 → 点亮
    }
    else                                                    // 当前是低电平（亮）
    {
        GPIO_SetBits(GPIOB, GPIO_Pin_10);                  // 拉高 → 熄灭
    }
}
```

> 这里用的是 `GPIO_ReadOutputDataBit()`，读取的是**输出数据寄存器**（ODR）中保存的当前输出电平，
> 而不是引脚上的实际电压，因此不会受外部电路影响，适合用来记录"灯现在是什么状态"。

```
│   ├── stm32f10x_it.c   中断服务函数
│   └── stm32f10x_conf.h 外设库配置头文件
├── Library/             STM32F10x 标准外设库
└── Startup/             启动文件与内核文件
```

### 延时函数说明

`Delay.c` 基于 **SysTick 定时器**实现，主频 72MHz：

- `Delay_us(x)`：微秒级延时，范围 0~233015
- `Delay_ms(x)`：毫秒级延时
- `Delay_s(x)`：秒级延时

相比空循环延时，SysTick 是硬件定时器，延时**更准确**，不受编译器优化影响。

## 六、使用方式

1. 用 **Keil MDK5** 打开 `1.uvprojx`
2. Rebuild（重新编译），确认 `0 Error(s)`
3. 连接 **ST-Link**，点击 **Download** 下载程序
4. 按下板上的按键，观察 LED 亮灭翻转，每次按压只翻转一次即为消抖成功

*实验环境：Keil MDK5 + STM32F10x 标准外设库 V3.5.0*
