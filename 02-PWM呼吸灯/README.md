# 02 - PWM 呼吸灯

## 功能

LED 亮度由暗逐渐变亮、再由亮逐渐变暗，循环往复，形成"呼吸"效果。

## 硬件连接

| 器件 | 引脚 | 模式 | 说明 |
|---|---|---|---|
| LED | PA0 | 复用推挽输出（AF_PP） | 对应 TIM2_CH1 |

> 注意：PA0 是 TIM2 的通道 1，必须使用该引脚才能输出 PWM，普通 GPIO 推挽输出是做不到的。

## 实现思路

用定时器的 PWM 模式输出方波，通过不断改变**比较值（CCR）**来调节占空比，占空比越大 LED 越亮，从而形成渐变。

```c
while (1)
{
    for (int i = 0; i <= 100; i++)          // 占空比 0% → 100%，逐渐变亮
    {
        TIM_SetCompare1(TIM2, i);
        Delay_ms(20);
    }
    for (int i = 0; i <= 100; i++)          // 占空比 100% → 0%，逐渐变暗
    {
        TIM_SetCompare1(TIM2, 100 - i);
        Delay_ms(20);
    }
}
```

## 定时器参数

| 参数 | 值 | 说明 |
|---|---|---|
| 系统时钟 | 72 MHz | 定时器挂在 APB1 总线上 |
| 预分频系数 PSC | 720 - 1 | 72 MHz ÷ 720 = **100 kHz** 计数频率 |
| 自动重装值 ARR | 100 | 100 kHz ÷ 100 = **1 kHz** PWM 频率 |
| PWM 模式 | PWM1 | 计数值小于 CCR 时输出有效电平 |
| 比较值 CCR | 0 ~ 100 | 决定占空比 |
| 每步延时 | 20 ms | 一个完整呼吸周期 = 200 步 × 20 ms = **4 秒** |

计算公式：

```
计数频率 = 72MHz / (PSC + 1)
PWM 频率 = 计数频率 / (ARR + 1)
占空比   = CCR / (ARR + 1) × 100%
```
